# R.O.B Architectural Studio

Architecture portfolio built with Next.js App Router, React, and GSAP. Preserves the existing design, .html URLs, metadata, hero slideshow, animations, filters, inquiry form, and WhatsApp greeting.

Run npm ci, then npm run dev. For production, run npm run check, npm run build, and npm start.

See [DEPLOYMENT.md](DEPLOYMENT.md) for editing locations, browser checks, and deployment settings.
